# Week 16 final submission package

This directory is the hand-off bundle for the completed research prototype. The formatted paper is `paper.pdf`; `paper.md` is the exact Markdown source used to produce it. Figure assets are copied under `figures/` so the paper can be regenerated or inspected without relying on a working-tree-relative path.

The declaration and certificate files are neutral institutional templates with clearly marked placeholders. No institution-specific synopsis or signed template was present in the repository, so these pages must be replaced or completed using the institution's official wording before filing.

See [`MANIFEST.md`](MANIFEST.md) for the required-deliverable inventory. The runnable demo remains in [`../demo/`](../demo/) and is launched with `python scripts/serve_week16_demo.py --port 8000` from the repository root. The reproducibility contract remains [`../config/reproducibility_freeze.json`](../config/reproducibility_freeze.json).
